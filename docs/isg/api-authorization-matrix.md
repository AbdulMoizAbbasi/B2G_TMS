# JazzRadar / B2G TMS — API Authorization Matrix

This matrix was derived from route decorators and dependency signatures in `backend/main.py`, plus the authorization logic in the handlers. “Authenticated” means a valid bearer JWT with a present, active, non-revoked, non-idle `auth_sessions` row through `get_current_user()`. The application’s docs/OpenAPI routes are FastAPI defaults and are not declared with application dependencies.

Existing tests are concentrated in `backend/tests/test_auth_sessions.py`; they do not test every row. “No route-specific test” means no direct test was found in that file, not that no manual or external test exists.
