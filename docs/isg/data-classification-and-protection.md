No formal JazzWorld data-classification policy or approved labels were found in the repository. The suggested sensitivity descriptions below are **proposals for ISG/data-owner review**, not formal classifications.

## Storage and transmission boundaries

- Compose mounts `./data` at `/app/data`; actual host filesystem permissions and encryption are infrastructure evidence.
- MariaDB uses the Compose named volume. No database TLS or at-rest encryption settings are visible in `backend/database/connection.py` or Compose.
- Browser/Nginx/API are configured for HTTP in repository files. External TLS termination may exist but is not evidenced.
- Backend sends a subset of tender, employee, and coordinator data to a configured Power Automate endpoint for assignment email. Endpoint ownership, access controls, retention, and data-processing arrangements require confirmation.
- An internal alert API returns tender/participation/contact reports to callers with the service key. Caller identity and endpoint network restriction are not visible.

## Backup and retention evidence required

No automated backup schedule, restore test, retention period, data-subject process, or verified encryption-at-rest setting was found. ISG and data owners should confirm classification, retention, backup scope (MariaDB volume plus `data` files/checkpoints), encryption, restore objectives, and access controls before internal or production deployment.
